# What's Dail

Android speed dial for WhatsApp. Assign names and numbers to keys 0–9, with phone contact picker support. Long-press an assigned key to open its WhatsApp chat. WhatsApp does not expose a supported API to automatically place personal voice calls, so tap Call in WhatsApp.

GitHub Actions builds a debug APK on each push to main. Download it from the workflow run Artifacts. Debug builds are for testing, not Play Store release.
